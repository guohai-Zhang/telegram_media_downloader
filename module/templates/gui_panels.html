Telegram API 凭证
如何获取 api_id 和 api_hash？
  1. 用浏览器打开 my.telegram.org（在国内需要开代理），输入带国家区号的手机号，把 Telegram App 里收到的验证码填进去登录。
  2. 点击 API development tools。
  3. App title 和 Short name 随便填英文，Platform 选 Desktop，点 Create application。
  4. 页面上的 App api_id 和 App api_hash 就是这里要填的两项。创建时如果提示 ERROR，多试几次或换一个代理节点。
代理

在国内需要代理才能连接 Telegram。Clash 等工具一般填 127.0.0.1，端口 7890。
